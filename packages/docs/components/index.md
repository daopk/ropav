# Components

Every component below is built, tested and themed. The ones with a page here are the ones a
project reaches for first — each has a playground, worked examples, and the props read straight
off the source.

The rest are in [Storybook](/guide/storybook), which is generated from the same files and stays
in step with them by construction. They are not lesser components; they are the ones whose pages
have not been written yet.

::: tip Names in grey are the Storybook ones
A build is only given a Storybook address when it has one to give, so a public page shows those
names as plain text rather than as a link to somebody's laptop. Run Storybook locally and they
are all a click away.
:::
